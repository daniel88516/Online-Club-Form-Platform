線上表單系統

專題採分組方式(每組1-3人)，請利用HTML + CSS + Bootstrap 5 + JavaScript(jQuery) + Ajax + PHP + MySQL ，

參考 Google表單 功能，設計一線上表單系統，專題基本要求如下：

◎可使用HTML/CSS框架(如:Bootstrap)設計，可參考引用網路其他相關網站之資料，但應注意不可有侵權之行為。網站各頁面樣式應具一致性(套用相同CSS)、並符合RWD(Responsive Web Design)設計原則 。

◎具有會員線上註冊功能，利用Ajax檢查帳號是否存在，並利用JavaScript(jQuery)做表單驗證(Form validation)。

◎會員可歸屬不同的群組(如單位、等級、族群...等，規則可自訂)。

◎會員可新增表單，自訂各式表單欄位(如:簡答、詳答、選擇題、核取方塊....等)，可設定表單填答對象、填答期間、是否可重複填答...等，並可預覽及發布表單。

◎可表列目前的所有表單，並可排序、查詢、修改及刪除表單。

◎可查看目前表單的填答情形並做資料統計。

◎關聯式資料庫規劃(限MySQL資料庫)，所有資料來自資料庫。

◎所有系統功能操作應具便利性並提供適當的訊息回饋。

◎網站系統至少應具有三種使用者身份：
v一般使用者：不需要登入系統即可查詢公開的資訊(.如：系統公告、表單列表....等)。
v會員：登入系統後具有會員權限 (專題上傳前需新增以下會員帳號供老師測試 member/member123456 )
v系統管理者：登入系統後具管理者權限 (專題上傳需前新增以下管理者帳號供老師測試 admin/admin123456 )，可針對所有會員及表單等資料進行新增、修改、刪除及查詢(具CRUD操作功能)。

◎系統權限控管：系統需具有使用者身份認證及授權(不同使用者具有不同的權限)功能，
所有頁面必需要檢查權限，未登入或權限不足者需強迫導向至登入頁面(如:非管理者直接輸入會員管理的網址)

◎其他功能應用(自訂)
