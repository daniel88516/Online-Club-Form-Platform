# 線上社團與表單平台

這是一套以 PHP 與 MariaDB/MySQL 建置的線上社團與表單平台，目標是將社團經營、活動問卷、會員互動與後台管理集中到同一個網站中。系統不只提供一般表單填寫，也將表單做為社群內容的一部分，讓使用者能建立、發布、回覆、討論與追蹤各項活動或意見蒐集。

## 核心功能

- **帳號與權限管理**：提供註冊、登入、登出與帳號資料驗證；依訪客、一般會員與管理員區分可使用的功能與資料範圍。
- **動態表單建立**：可建立問卷或活動表單，設定標題、說明、封面、開放時間、回覆對象、匿名回覆、多次填答與統計公開方式。題型支援文字、數字、單選、多選、下拉、日期與時間等形式。
- **回覆與統計**：回覆資料由資料庫保存，表單擁有者可查看填答明細與統計結果；選擇題可用 Chart.js 呈現分布，文字題則保留個別回覆內容。
- **社群互動**：表單可被按讚、收藏與留言，留言支援巢狀回覆與圖片；使用者可管理自己的表單、收藏與互動紀錄。
- **社團管理**：使用者可建立公開或私人社團，處理加入申請與邀請，並將表單發布到一個或多個社團，讓活動與問卷有明確的受眾。
- **個人化與訊息**：提供個人檔案、頭像與背景圖上傳、個人簡介、站內私訊及系統通知；介面支援明暗主題與自訂主題色彩。
- **管理後台**：管理員可管理會員、表單、社團與檢舉內容，並透過搜尋、排序、審核與 CRUD 操作維持平台資料品質。

## 技術重點

前端以 HTML、CSS、Bootstrap 5、JavaScript/jQuery 與 AJAX 建立響應式、即時回饋的操作流程；表單統計使用 Chart.js。後端以 PHP 處理登入 Session、資料驗證、權限判斷與 API，並以 MariaDB/MySQL 設計使用者、表單欄位、回覆、留言、按讚、收藏、社團、私訊與檢舉等關聯資料表。

## 專案內容

`admin/` 為管理後台，`member/` 為會員功能，`api/` 放置 AJAX API，`config/` 集中設定與共用元件；另附資料庫匯入／匯出腳本與期末專題文件。
